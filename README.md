One line from the office printer itself: after 41,209 flawless pages, it finally talks back — entry for [The Printer Finally Answers](https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907) on make.fun.

## How it works

`main.py` writes a single line of text (1–240 characters) to `/output/entry.txt`. Deterministic: no network, no randomness, no clock — the same bytes on every run.

## Run locally

```sh
python3 main.py
cat /output/entry.txt
```
